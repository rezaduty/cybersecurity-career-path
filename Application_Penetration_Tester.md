# Resumen

Una prueba de penetración, conocida coloquialmente como pentest o hacking ético, es un ciberataque simulado y autorizado contra un sistema informático, realizada para evaluar la seguridad del sistema. El pentest de **aplicaciones** (web, móvil, APIs, clientes gruesos) combina análisis de caja negra y caja blanca para evaluar la seguridad del software en profundidad, incluyendo revisión manual de código fuente.

# Requisitos previos

* Conocimiento de algún lenguaje de programación (C#, Java, JavaScript, Python, C++, etc.)
* Conocimiento de alguna arquitectura de aplicaciones (monolítica, microservicios, basada en eventos, etc.)

# Habilidades técnicas

* Experiencia realizando pruebas de penetración de aplicaciones en caja blanca (web, APIs, móvil, clientes gruesos) o capacidad de demostrar conocimiento equivalente.
* Excelentes habilidades con herramientas de prueba de seguridad de aplicaciones: Burp Suite, OWASP ZAP, SQLMap, Frida, Ghidra, IDA Pro, Kali Linux.
* Experiencia realizando revisiones manuales de seguridad del código fuente en varios lenguajes: Java, .NET (C#, VB.NET), C++, Python, JavaScript/TypeScript.
* Experiencia con UNIX o Linux.
* Experiencia con lenguajes de scripting: Python, Bash, PowerShell.
* Conocimiento de contenedores, Kubernetes y tecnologías cloud (AWS, Azure, GCP).
* Familiaridad con el ciclo de vida de desarrollo seguro (SSDLC), SAST/DAST/SCA y su integración en pipelines CI/CD (skill muy demandado en 2026).

# Habilidades blandas

* Motivación propia y capacidad de iniciativa: si hay una duda, ser proactivo para encontrar la respuesta y comunicar lo aprendido al equipo.
* Pasión por la seguridad de las aplicaciones, deseo de seguir creciendo en este ámbito y capacidad de compartir esa pasión y conocimiento con el equipo.

# Educación

  * Grado en Ciencias de la Computación, Ingeniería Informática, Ingeniería Eléctrica o experiencia equivalente.

# Certificaciones

  * CEH (base, valiosa para roles GRC y gobierno)
  * OSCP (estándar ofensivo, validez vitalicia)
  * eWPT / eWPTX (aplicaciones web)
  * eMAPT (aplicaciones móviles)
  * OSWE (Web Expert) y OSED (Exploit Development) para niveles avanzados
