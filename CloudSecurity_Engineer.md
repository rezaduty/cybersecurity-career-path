# Resumen

Se requiere un Ingeniero de Seguridad en la Nube para una empresa de servicios cloud en rápido crecimiento, trabajando con infraestructura cloud que abarca entornos AWS, Google Cloud (GCP) y OpenStack. Será responsable de asegurar la infraestructura cloud implementando buenas prácticas y estrategias de prevención de vulnerabilidades. Sus funciones incluirán asegurar aplicaciones contenerizadas en Docker y Kubernetes, garantizar procesos de despliegue seguros, realizar auditorías periódicas de seguridad cloud, y trabajar en estrecha colaboración con los equipos de desarrollo y operaciones para monitorizar y mitigar riesgos de seguridad. También gestionará la automatización de procesos de seguridad, integrará herramientas de seguridad y garantizará el cumplimiento de estándares de la industria como PCI DSS y GDPR. Es uno de los roles mejor pagados y de mayor demanda en 2026.

# Requisitos previos

- Experiencia en entornos AWS, GCP y/o Azure
- Familiaridad con tecnologías de contenedorización (Docker, Kubernetes)
- Sólida comprensión de políticas de seguridad cloud y cumplimiento normativo

# Habilidades técnicas

- Experiencia práctica profunda con servicios de AWS: IAM, EC2, S3, RDS, VPC, Lambda y KMS (además de GuardDuty, Security Hub, WAF, CloudTrail).
- Conocimiento de servicios de Google Cloud: Identity Platform, Cloud IAM, Cloud Run, GCR/Artifact Registry, Cloud Logging (Stackdriver) y Cloud Security Scanner.
- Experiencia trabajando con entornos OpenStack, configurando y asegurando sus componentes.
- Prácticas de seguridad de Docker y Kubernetes: políticas de pod security (Pod Security Standards/Admission, OPA/Gatekeeper), RBAC y políticas de red.
- Dominio de herramientas de Infraestructura como Código (IaC): Terraform, OpenTofu y Ansible para automatizar configuraciones de seguridad.
- Conocimiento de scripting en Python, Bash o Go para automatizar comprobaciones y auditorías de seguridad.
- Familiaridad con herramientas de análisis de vulnerabilidades (Trivy, Clair, Grype para imágenes de contenedores) y herramientas de protección en runtime como Falco.
- Experiencia implementando firewalls, WAF, IDS/IPS y herramientas de monitorización (CloudWatch, GCP, Azure Monitor) para seguridad cloud.
- (2026) Modelo de responsabilidad compartida, Zero Trust en la nube, CSPM/CNAPP (Wiz, Prisma, Orca, Lacework), seguridad serverless y supply chain de imágenes.

# Habilidades blandas

- Capacidad de comunicar conceptos de seguridad complejos a partes interesadas no técnicas.
- Fuertes habilidades de resolución de problemas y respuesta a incidentes en entornos de alta presión.
- Colaboración con equipos multifuncionales (DevOps, ingeniería, operaciones) para integrar la seguridad en los flujos de desarrollo.
- Aprendizaje continuo y adaptación a las amenazas y soluciones de seguridad cloud en evolución.
