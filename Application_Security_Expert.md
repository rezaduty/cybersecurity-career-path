# Resumen

Como miembro del equipo de Infraestructura y Seguridad de la Información, se da soporte a la infraestructura cloud desarrollando herramientas, construyendo servicios y prestando servicios de consultoría a los equipos de ingeniería. Se es una pieza clave en la protección de los datos de los clientes que confían su contenido a la empresa cada día: planificar y ejecutar medidas de seguridad para monitorizar y proteger datos y sistemas sensibles de infiltraciones y ciberataques.

En 2026, este rol suele llamarse también **Application Security Engineer (AppSec)**.

# Requisitos previos

* Conocimiento de arquitecturas de frameworks (frameworks de aplicación, servidores, bases de datos)
* Experiencia con ciclos de vida de desarrollo y CI/CD

# Habilidades técnicas

* Familiaridad con el framework MITRE ATT&CK.
* Liderar o realizar emulaciones de adversarios.
* Familiaridad con frameworks de emulación de adversarios de la industria como CBEST, iCAST y GFMA.
* Liderar o realizar pruebas de Equipo Púrpura (Purple Team).
* Participación en operaciones de Cyber Tiger Team.
* Realizar evaluaciones de vulnerabilidades y pruebas de penetración (aplicación y/o infraestructura) y comunicar los problemas de seguridad a audiencias técnicas y no técnicas.
* Identificar, investigar, validar y explotar diversas vulnerabilidades de seguridad conocidas y desconocidas, del lado del servidor y del cliente.
* Reportar vulnerabilidades de seguridad de la información a las áreas de negocio y a la alta dirección.
* Proporcionar soporte en los esfuerzos de remediación.
* Infraestructura de aplicaciones web: servidores de aplicaciones, servidores web, bases de datos.
* Experiencia con la automatización de pruebas de seguridad como parte de un pipeline de CI/CD.
* Desarrollo web y lenguajes de programación: Python, Perl, Ruby, Java, .NET, Go.
* Desarrollar e implementar el ciclo de vida de desarrollo de software seguro (SSDLC).
* Experiencia con alguna de las herramientas de seguridad de aplicaciones: Checkmarx, Sonatype, OWASP ZAP, Burp Suite, Snyk, Semgrep, Veracode.
* Experiencia en seguridad cloud, incluida AWS (IAM, GuardDuty, Security Hub, WAF).

# Habilidades blandas

* Aprendizaje continuo en el trabajo.
* Se busca construir cosas seguras, no solo romperlas.

# Educación

  * Grado en Ciencias de la Computación, Ingeniería Informática, Ingeniería Eléctrica o experiencia equivalente.

# Certificaciones

  * CSSLP (ISC2, Secure Software Lifecycle Professional)
  * GSSP-Java / GSSP-.NET (GIAC) o GWEB
  * OSCP (base ofensiva, muy común en roles AppSec en 2026)
  * AWS Security Specialty / CCSP si el rol es cloud
