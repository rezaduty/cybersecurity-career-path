# Resumen

El rol de **Ingeniero de Seguridad de Datos** implica garantizar la seguridad de los entornos de big data aplicando técnicas de inteligencia artificial y análisis de big data para identificar, mitigar y prevenir vulnerabilidades de seguridad. El ingeniero se encarga de asegurar las pipelines de datos, implementar cifrado robusto, gestionar el control de acceso y garantizar que los modelos de ciencia de datos e IA dentro de una organización no se vean comprometidos. Trabajan en estrecha colaboración con los equipos de ciencia de datos para proteger los datos sensibles tanto de amenazas externas (p. ej., hackers) como internas (p. ej., mala gestión o fugas de datos), garantizando la integridad y fiabilidad de los datos críticos de negocio. En 2026, la seguridad de la IA (ML-Security, protección de modelos y pipelines) es una habilidad diferenciadora clave.

# Requisitos previos

- Conocimiento profundo de IA, sistemas de big data y protocolos de seguridad.
- Experiencia asegurando entornos de datos a gran escala, incluidos sistemas cloud y on-premises.
- Familiaridad con las últimas tendencias y herramientas en seguridad de datos y detección de vulnerabilidades impulsada por IA.

# Habilidades técnicas

- Sólida experiencia con frameworks de big data: Hadoop, Spark y bases de datos NoSQL (p. ej., MongoDB, Cassandra, ClickHouse).
- Experiencia en machine learning y IA para identificar vulnerabilidades de seguridad, incluidas técnicas de detección de anomalías.
- Experiencia práctica con técnicas de cifrado de datos, control de acceso basado en roles (RBAC) y autenticación multifactor (MFA).
- Dominio de herramientas de seguridad de big data como Apache Ranger, Apache Knox y Apache Sentry para asegurar grandes conjuntos de datos.
- Comprensión de las normativas de privacidad de datos (GDPR, CCPA/LGPD) y cómo afectan a los sistemas de IA y big data.
- Familiaridad con la seguridad cloud, particularmente en plataformas como AWS, Google Cloud y Azure, con herramientas como GuardDuty, KMS, AWS Macie e IAM para asegurar las pipelines de datos.
- (2026) Seguridad de la cadena de suministro de modelos: MLflow, firmado de modelos, federated learning adversario, privacidad diferencial, y testing de sesgos/robustez de modelos (OWASP ML Top 10).

# Habilidades blandas

- Excelentes habilidades de resolución de problemas y capacidad de trabajar con grandes equipos multifuncionales, incluidos científicos de datos e ingenieros de IA.
- Fuertes habilidades de comunicación para trasladar medidas de seguridad complejas a equipos no técnicos.
- Actitud proactiva para mantenerse al día de la naturaleza cambiante de las amenazas de seguridad de IA y big data.

# Educación

- Grado en Ciencias de la Computación, Ciberseguridad o campos relacionados.
- Certificaciones avanzadas en seguridad de datos o IA (opcional, pero beneficiosas).
