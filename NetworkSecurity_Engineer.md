# Resumen

Una organización tecnológica líder requiere un Ingeniero de Seguridad de Redes para diseñar, implementar y gestionar la infraestructura de seguridad que protege la red frente a vulnerabilidades. Se utilizan soluciones de seguridad de red, incluidos Cisco, Fortinet, Sophos, F5 y Mikrotik, para garantizar la seguridad e integridad de la arquitectura de red de la empresa. El rol incluye auditoría periódica de las configuraciones de seguridad, gestión proactiva de amenazas y configuración de políticas de seguridad para mitigar riesgos. En 2026, este rol ha evolucionado hacia el concepto de Zero Trust / SASE: además del perímetro clásico, se protegen accesos remotos, segmentación y tráfico cifrado.

# Requisitos previos

* Base sólida de redes (CCNA o conocimiento equivalente)
* Conocimiento de sistemas operativos y administración de firewalls

# Habilidades técnicas

- Soporte al despliegue y mantenimiento de dispositivos de seguridad de red (firewalls, VPN, sistemas IDS/IPS) en la red de la empresa.
- Colaboración con administradores de red para gestionar el flujo de tráfico y segmentar los recursos de la red.
- Implementar políticas y procedimientos de seguridad de red para mitigar riesgos.
- Realizar evaluaciones de vulnerabilidades y pruebas de penetración para evaluar la fortaleza de las defensas de seguridad.
- Monitorizar y responder a eventos de seguridad de red, incluidos intentos de intrusión y brotes de malware.
- Experiencia con soluciones de seguridad de red como Cisco ASA/Firepower, Fortinet FortiGate, Sophos XG Firewall, F5 BIG-IP y Mikrotik RouterOS.
- Sólido conocimiento de protocolos de red (TCP/IP, DNS, HTTP/S, BGP, OSPF, etc.) y experiencia asegurando estos protocolos.
- Dominio en la configuración y gestión de reglas de firewall, VPN, certificados SSL/TLS y sistemas IDS/IPS (Snort, Suricata, Cisco).
- Experiencia práctica con funcionalidades de firewalls de nueva generación (NGFW): Control de Aplicaciones, IPS y Puertas de Enlace Web Seguras (SWG).
- Familiaridad con herramientas de monitorización de seguridad de red como Wireshark, Zeek (anteriormente Bro) y SolarWinds.
- Experiencia con redes privadas virtuales (VPN) para acceso remoto seguro (SSL VPN, IPSec VPN).
- Comprensión de marcos y estándares de seguridad como NIST, ISO 27001 y benchmarks CIS para seguridad de red.
- (2026) Conocimiento de Zero Trust Network Access (ZTNA), SSE/SASE, microsegmentación, y seguridad de tráfico cifrado (MITM/inspección TLS).

# Habilidades blandas

- Capacidad de gestionar múltiples incidentes de seguridad y priorizar tareas en un entorno de alta presión.
- Fuertes habilidades de comunicación para colaborar con equipos de red y seguridad, así como explicar problemas de seguridad a interesados no técnicos.
- Gran atención al detalle y enfoque proactivo en la detección y mitigación de amenazas.
- Aprendizaje continuo para mantenerse al día de las últimas amenazas y avances tecnológicos en seguridad de red.
